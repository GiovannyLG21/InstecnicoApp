# 📱 InstecnicoApp

**InstecnicoApp** es una propuesta de aplicación móvil para instituciones educativas que permite a los estudiantes y usuarios gestionar trámites académicos, consultar información institucional y estar al tanto de noticias relevantes en un solo lugar.

---

## ✨ Características

- Acceso rápido a trámites académicos y administrativos.
- Visualización del estado de solicitudes como aprobadas, pendientes o rechazadas.
- Consulta de noticias e información institucional.
- Interfaz adaptada a dispositivos móviles con un diseño limpio y moderno.
- Organización visual de documentos y procesos importantes para estudiantes.
- Experiencia enfocada en simplicidad, usabilidad y rapidez.

## 🚀 Instalación

### 1. Clonar el repositorio

```bash
git clone https://github.com/GiovannyLG21/InstecnicoApp.git
cd InstecnicoApp
```

### 2. Abrir el proyecto

Puedes abrir directamente el archivo `index.html` en tu navegador o ejecutar un servidor local.

### 3. Ejecutar servidor local

```bash
python -m http.server 8000
```

Luego accede a:

```bash
http://localhost:8000
```

## 📦 Despliegue / producción

Este proyecto funciona como una vista estática y puede desplegarse fácilmente en servicios de hosting web estático o portarse a una aplicación móvil con tecnologías nativas o híbridas.

Si deseas probar la versión local, solo basta con servir la carpeta raíz del proyecto.
